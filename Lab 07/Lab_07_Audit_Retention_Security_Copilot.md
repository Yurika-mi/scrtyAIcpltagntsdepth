# ラボ 07: Purview 監査、保持、および Security Copilot

## はじめに

Zava Corporation AI セキュリティコースの最終ラボは、監査調査、データライフサイクル管理、および AI 支援セキュリティ分析をまとめたものです。Microsoft Purview は、すべての Copilot とエージェントインタラクションを構造化監査レコードとしてキャプチャします。プロンプトコンテキスト、参照されるファイル、および適用される機密性ラベルが含まれます。これらのレコードはコンプライアンス義務のために保持でき、フォレンジック調査のために検索でき、Security Copilot の組み込みインテリジェンスを使用して分析できます。

このラボでは、Patti Fernandes が対象となるエージェントインタラクションシグナルを生成して監査ログを作成し、Purview 監査を使用してそれらのインタラクションを調査します。CopilotInteraction イベントと Copilot Studio エージェント管理イベントを検索します。保持ポリシーを作成して、すべての Copilot とエージェントインタラクションデータのライフサイクルを管理します。その後、Patti は Security Copilot を使用します。Purview に組み込まれたものとスタンドアロンポータルの両方を使用して、DLP アラートを要約し、組織の AI セキュリティ体勢に関するクエリを実行します。

---

## シナリオ

Zava の法務チームは、すべての AI エージェントインタラクションデータを最低 5 年間保持するよう要求しました。金融サービス規制要件を満たすためです。同時に、CISO は SOC チームに対して、Purview 監査が Zava エージェント資産から意味のあるフォレンジックデータをキャプチャしており、Security Copilot が AI 関連セキュリティイベントのトリアージを加速できることを実証するよう要求しました。

Patti Fernandes は Zava HR Assistant の監査レコードを調査し、エージェントの作成と公開から記録されたエージェント管理イベントをレビューし、DLP マッチイベントが記録されていることを確認します。ODL ユーザーが保持ポリシーを作成および検証します。Patti はセキュリティコースを完了します。Security Copilot を使用して、Zava 環境全体の 2 日目と 3 日目のセキュリティ検出結果をまとめます。

---

## 目的

- Zava HR Assistant を使用して Patti Fernandes としてエージェントインタラクション監査シグナルを生成する。
- Purview 監査で `CopilotInteraction` イベントを検索し、インタラクションレコードフィールドをレビューする。
- Copilot Studio エージェント管理イベント — 公開、構成、および更新アクティビティを検索する。
- ラボ 04 およびラボ 06 ポリシーによって生成された DLP マッチ監査レコードをレビューする。
- すべてのユーザーにスコープされた Copilot および AI アプリインタラクションの保持ポリシーを作成する。
- 保持ポリシーの構成を検証し、ポリシーの場所が Copilot Studio をカバーしていることを確認する。
- Purview の Security Copilot を使用して DLP アラートをまとめ、AI 体勢にクエリを実行する。
- スタンドアロンの Security Copilot を使用して、Zava エージェント検出にスコープされたカスタムプロンプトを実行する。

    ```
    https://copilot.microsoft.com
    ```

    - **パスワード:** <inject key="User's Password"></inject>

2. Microsoft 365 Copilot チャットインターフェイスで、**Zava HR Assistant** を検索して選択します。

3. チャット入力フィールドに以下のプロンプトを入力します:

   ```
   Zava の年間休暇取得ポリシーはどのようなものですか？

4. Zava HR Assistant の応答を待ちます。

	![](./media/n2.png)

   Zava における従業員オンボーディングプロセスをお見せいただけますか？
   ```

6. 応答を待ちます。

	![](./media/n3.png)

7. 機密ラベル付きファイルを参照する以下の 3 番目のプロンプトを入力します:

    ```
    Zava の従業員記録にはどのような詳細情報が含まれていますか？
    ```

8. 応答を待ち、ラボ 04 の DLP ポリシーが応答をブロックするか許可するかをメモします。

	![](./media/n4.png)

9. 以下の 4 番目のプロンプトを入力します:

    ```
    病欠報告書に記載されている従業員は誰ですか？
    ```

10. 応答を待ち、結果をメモします。

	![](./media/n5.png)

    > **注:** これらの 4 つのプロンプトは、Zava HR Assistant にスコープされた `CopilotInteraction` 監査イベントを生成します。プロンプト 3 と 4 は、**Zava-Confidential/HR-Data** 機密性ラベルを持つファイルを参照しており、ラボ 04 ポリシーが適用されている場合、監査ログに DLP マッチイベントを生成します。ここで生成された監査レコードは、エクササイズ 2 の主要な調査対象です。

11. InPrivate ブラウザーウィンドウを閉じます。

## エクササイズ 2: Purview 監査で Copilot インタラクションイベントを調査する [オプション]

### タスク 1: CopilotInteraction イベントを検索する

1. 新しい **InPrivate** または **Incognito** ブラウザーウィンドウを開きます。`https://purview.microsoft.com` にナビゲートします。**リソース** タブから **Patti Fernandes** の認証情報でサインインします。

    - **メール:** <inject key="User 02 UPN"></inject>
    - **パスワード:** <inject key="User's Password"></inject>

2. 左ナビゲーションペインから、**ソリューション** > **監査** を選択します。

	![](./media/l07-e2-t1-s2.png)

3. 以下の値で検索を構成します:

   - **開始日:** 本日から 7 日前を選択します。
   - **終了日:** 本日を選択します。
   - **アクティビティ – フレンドリー名:** `Copilot activities` と入力し、ドロップダウンから **Interacted with Copilot** を選択します。
   - **ユーザー:** `Patti Fernandes` と入力し、結果からアカウントを選択します。

4. **検索** を選択します。

	![](./media/l07-e2-t1-s4.png)

5. 検索ジョブが完了するまで待ちます。

6. Adele Vance の Copilot インタラクションで返された結果をレビューします。

---

### タスク 2: CopilotInteraction 監査レコードを詳細にレビューする [オプション]

1. 検索結果から、任意のインタラクションエントリを選択して監査レコード詳細パネルを開きます。

2. 詳細パネルで、**監査データ** セクションの以下のフィールドをレビューします:

   - **操作** — `CopilotInteraction` と表示されていることを確認します。
   - **ワークロード** — `Copilot` と表示されていることを確認します。
   - **UserId** — Adele Vance の UPN が表示されていることを確認します。
   - **AppHost** — インタラクションが発生したアプリケーションサーフェスをメモします。
   - **AccessedResources** — リストされているすべてのファイルをレビューします。ファイル名、サイト URL、および存在する場合は `SensitivityLabelId` をメモします。
   - **AISystemPlugin** — `BingWebSearch` が表示されるかどうかをメモします。これはインタラクションが Bing を使用したことを示します。
   - **ThreadId** — 会話スレッド識別子をメモします。

3. 詳細パネルを閉じます。

4. 検索結果から、機密ファイルを参照するインタラクションエントリを選択します。**AccessedResources** が入力されているエントリを探します。

5. 詳細パネルの **AccessedResources** で、以下を確認します:

   - ファイル名がラボ 00 でアップロードされた Zava HR SharePoint ファイルのいずれかと一致すること。
   - `SensitivityLabelId` フィールドが入力されており、ラボ 04 で適用されたラベルが監査証跡に記録されていることを確認します。

6. 詳細パネルを閉じます。

   > **注:** プロンプトと応答の全文は Purview 監査レコードに含まれていません。メタデータのみ — ファイル参照、ラベル ID、スレッド ID、およびインタラクションコンテキスト — がキャプチャされます。完全なトランスクリプトは DSPM アクティビティエクスプローラーでアクセス可能であり、ラボ 06 でレビューされています。これは設計によるものです。監査レコードはフォレンジック証跡を提供し、DSPM はコンテンツ調査サーフェスを提供します。

## エクササイズ 3: Copilot Studio エージェント管理イベントを検索する [オプション]

### タスク 1: エージェント管理監査イベントを検索する

1. **監査** ページで、**新規検索** を選択します。

2. 以下の値で検索を構成します:

   - **開始日:** ラボ 00 を完了した日付（コースの開始日）を選択します。
   - **終了日:** 本日を選択します。
   - **アクティビティ – フレンドリー名:** `Copilot Studio` と入力し、ドロップダウンから利用可能なすべての Copilot Studio アクティビティタイプを選択します:
     - **Published an agent**
     - **Updated an agent**
     - **Deleted an agent**
     - **Configured an agent**
   - **ユーザー:** すべてのユーザーを検索するには空白のままにします。

3. **検索** を選択します。

4. 検索ジョブが完了するまで待ちます。

5. 結果をレビューします。

6. ラボ 00 で公開された Zava エージェントの 1 つに対応する **Published an agent** エントリを探します。

7. エントリを選択して詳細パネルを開きます。

8. 以下のフィールドをレビューします:

   - **操作** — 公開アクションを反映していることを確認します。
   - **UserId** — ODL ユーザー UPN が表示されていることを確認します。
   - **ObjectId** — エージェント識別子をメモします。
   - **AgentName** — 3 つの Zava エージェントのいずれかと一致することを確認します。

9. 詳細パネルを閉じます。

    > **注:** Copilot Studio エージェント管理イベントはすべてのテナントに対して自動的に記録されます。追加の構成は不要です。これらのイベントは、エージェント管理者が誰がエージェントを公開したか、最後に構成した時期、ナレッジソースまたは指示に変更が加えられたかどうかなど、エージェントのライフサイクルアクションの管理監査証跡を提供します。

## エクササイズ 4: DLP マッチイベントを検索し、保持ポリシーを作成する

### タスク 1: DLP マッチイベントを検索する [オプション]

1. **監査** ページで、**新規検索** を選択します。

2. 以下の値で検索を構成します:

   - **開始日:** 本日から 7 日前を選択します。
   - **終了日:** 本日を選択します。
   - **アクティビティ – フレンドリー名:** `DLP` と入力し、ドロップダウンから **DLP rule matched** を選択します。
   - **ユーザー:** 空白のままにします。

3. **検索** を選択します。

4. 検索ジョブが完了するまで待ちます。

5. 返された結果をレビューします。

6. DLP マッチイベントが存在する場合、エントリを選択して詳細パネルを開きます。

7. 詳細パネルで、以下のフィールドをメモします:

   - **ポリシー名** — ラボ 04 の **Zava - Block HR Data in M365 Copilot** ポリシーを参照していることを確認します。
   - **ルール名** — **Block Copilot access to HR-labelled content** を参照していることを確認します。
   - **機密性ラベル** — マッチをトリガーしたラベルを確認します。
   - **ユーザー** — Adele Vance が表示されていることを確認します。
   - **場所** — Microsoft 365 Copilot の場所を表示していることを確認します。

8. 詳細パネルを閉じます。

   > **注:** DLP マッチイベントがまだ表示されていない場合は、DLP ポリシーがまだ Copilot の場所に伝播中であることを示します。Copilot の場所の DLP イベントは、適用後、監査ログに表示されるまで最大 1 時間かかることがあります。結果がまだ利用可能でない場合は、エクササイズ 4 を完了してから、この検索に戻ります。

### タスク 2: ODL ユーザーとして保持ポリシーを作成する

1. 新しいブラウザータブを開き、**ODL ユーザー** として `https://purview.microsoft.com` にサインインします。左ナビゲーションペインで、**ソリューション** から **データライフサイクル管理** を選択します。

    ```
    https://purview.microsoft.com
    ```

	![](./media/l07-e4-t2-s1.png)

2. 左サブナビゲーションから、**ポリシー** の下の **保持ポリシー** を選択し、**+ 新しい保持ポリシー** をクリックします。

	![](./media/l07-e4-t2-s2.png)

3. **保持ポリシーに名前を付ける** ページで、以下を入力します:

   - **名前:** `Zava - AI インタラクション 5 年保持ポリシー`
   - **説明:** `Microsoft 365 Copilot および Copilot Studio エージェントのすべてのインタラクションデータ（プロンプトと応答を含む）を、Zava の金融サービス規制要件を満たすために最低 5 年間保持します。`

4. Zava の財務サービス規制要件を満たすために、プロンプトと応答を含むすべての Microsoft 365 Copilot および Copilot Studio エージェントインタラクションデータを最低 5 年間保持します。」と入力します。

5. **タイプ** を選択するよう求められるまで **次へ** を選択します。

	![](./media/l07-e4-t2-s4.png)

6. **作成する保持ポリシーのタイプを選択** ページで、**静的** を選択して **次へ** をクリックします。

	![](./media/l07-e4-t2-s5.png)

7. **このポリシーを適用する場所を選択** ページで、デフォルトで **オン** に切り替えられているすべての場所の選択を解除します。**Microsoft Copilot エクスペリエンス** を **オン** に切り替えます。

8. スコープが含まれるエントリの下に **すべてのユーザー** を表示していることを確認します。

   > **注:** **Microsoft Copilot エクスペリエンス** 保持場所は、Microsoft 365 Copilot と Copilot Studio エージェント両方のユーザープロンプトと応答をカバーします。インタラクションデータは、各ユーザーの隠しExchange メールボックスフォルダーに保存されます。ユーザーまたは管理者が直接アクセスすることはできませんが、eDiscovery で検索可能で、ここで構成されている保持ポリシーに従います。

9. **次へ** を選択します。

	![](./media/l07-e4-t2-s8.png)

10. **コンテンツを保持する、削除する、またはその両方を実行するかを決定** ページで、以下のように構成します:

   - **特定の期間アイテムを保持:** **5 年** を選択します。
   - **保持期間の開始基準:** **アイテムが作成された時期** を選択します。
   - **保持期間の終了時:** **何もしない** を選択します。

11. **次へ** をクリックします。

	![](./media/l07-e4-t2-s10.png)

12. **レビューして完了** ページで、完全なポリシー構成をレビューして **送信** を選択します。

	![](./media/l07-e4-t2-s13.png)

14. 確認ページで、**完了** を選択します。

	![](./media/l07-e4-t2-s14.png)

### タスク 3: 保持ポリシーを検証する

1. **保持ポリシー** ページで、**Zava - Retain AI Interactions 5 Year** を探します。

3. ポリシーを選択して詳細パネルを開きます。

	![](./media/n1.png)

4. 詳細パネルで、以下を確認します:

   - **ステータス** が **有効** であること。
   - **場所** が **Microsoft Copilot エクスペリエンス** を表示していること。
   - **保持期間** が **5 年** を表示していること。

	   ![](./media/l07-e4-t3-s4.png)

5. 詳細パネルを閉じます。

   > **注:** 新しい保持ポリシーがすべての選択された場所に配布され、既存のコンテンツに適用されるまで最大 7 日かかることがあります。ポリシーは、各 Zava ユーザーの隠しExchange メールボックスフォルダーに保存されているすべての新規および既存の Copilot およびエージェントインタラクションデータに適用されます。ユーザーが組織を離れる場合、そのインタラクションデータは保持期間全体にわたってこのポリシーの対象のままです。

## まとめ

このラボでは、Zava HR Assistant を 4 つのプロンプトで呼び出すことにより、Adele Vance として対象となる Copilot およびエージェントインタラクションシグナルを生成しました。機密ラベル付きの HR ファイルを参照する 2 つを含めて、意味のあるフォレンジック監査証跡を作成しました。Patti Fernandes として、Patti Fernandes にスコープされた CopilotInteraction イベントの Purview 監査を検索し、AccessedResources、SensitivityLabelId、AppHost、および ThreadId を含む構造化監査レコードフィールドをレビューし、機密性ラベルメタデータがインタラクション監査証跡にキャプチャされていることを確認しました。Copilot Studio エージェント管理イベントを検索し、Zava エージェントの 1 つの公開イベントレコードをレビューして、エンドツーエンドの管理監査チェーンを確認しました。DLP マッチイベントを検索して、ラボ 04 ポリシーがブロックされた HR ラベル付きコンテンツインタラクションの監査レコードを生成したことを確認しました。

Microsoft 365 Copilot および Copilot Chat の場所にスコープされた **Zava - Retain AI Interactions 5 Year** 保持ポリシーを作成し、Microsoft 365 Copilot およびCopilot Studio エージェント インタラクション全体のすべてのユーザーをカバーしました。ポリシーがアクティブであり、ユーザーの隠しExchange メールボックスフォルダーに保存されているすべてのインタラクションデータに適用されることを確認しました。

Zava Corporation AI セキュリティコースは完了しました。7 つのラボを通じて、包括的な AI セキュリティガバナンスフレームワークを構築しました。エージェント ID およびレジストリ管理から条件付きアクセス、データ分類、DLP、脅威ハンティング、オーバーシェアリング修復、監査、および保持まで — Microsoft セキュリティスタックを使用したエンタープライズ AI エージェントガバナンスの完全なライフサイクルをカバーしています。
