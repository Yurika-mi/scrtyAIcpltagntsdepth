# ラボ 04: Microsoft Purview — 秘密度ラベルと Copilot 用 DLP

## 概要

Zava の情報セキュリティチームは、Zava Finance Agent および Zava HR Assistant が、そのコンテンツがどの程度機密性を有しているかについての認識がないままSharePoint からコンテンツを取得し、表示できることを特定しました。CISO は Day 2 終了までにすべての機密 HR 文書および財務文書にラベルを付ける必要があることを義務付けており、Microsoft 365 Copilot は機密 HR データラベル付きドキュメントの処理を防止する必要があります。

Zava Corporation は、AI エージェントに接続されている SharePoint サイト全体で機密従業員記録、財務データ、およびベンダー契約を処理しています。秘密度ラベルおよび Data Loss Prevention ポリシーがなければ、これらのエージェントは、ユーザーのアクセス権またはデータ処理義務に関係なく、誰がどのような質問をしてもユーザーに保護コンテンツを表示することができます。

このラボでは、SharePoint および OneDrive の秘密度ラベルサポートを有効にし、ラベルグループおよび子ラベルを使用して Zava のラベル分類を構築し、財務データの自動ラベル付けを構成し、すべての Zava ユーザーにラベルを公開し、Microsoft 365 Copilot がラベル付きコンテンツの処理をブロックする DLP ポリシーを作成します。Patti Fernandes は、Copilot がラベル付きコンテンツの表示からブロックされているかどうか、および監査証跡をテストします。

---

## 目的

- SharePoint および OneDrive の秘密度ラベル共同編集サポートを有効にする。
- Zava ラベルグループと hr および Financial データ用の2つの子ラベルを作成する。
- 財務に機密な情報タイプを含むコンテンツに Financial Data ラベルを自動的に適用する自動ラベル付けポリシーを構成する。
- すべての Zava ユーザーに両方のラベルを公開する。
- Zava HRSharePoint ファイルに HR Data ラベルを手動で適用する。
- Microsoft 365 Copilot の場所をターゲットにして、HR ラベル付きコンテンツの処理をブロックする DLP ポリシーを作成する。
- Patti Fernandes として Microsoft 365 Copilot Chat を介して DLP 強制をテストする。
- Purview Audit で Patti Fernandes として DLP マッチ監査イベントを調査する。

## 演習 1: SharePoint および OneDrive の秘密度ラベルサポートを有効にする

### タスク 1: 秘密度ラベル付きファイルの共同編集を有効にする

1. ブラウザを開き、Microsoft Purview に移動します。プロンプトが表示された場合は **ODL User** 認証情報でサインインします。左側のナビゲーションペインで、**[設定]** を選択します。

https://purview.microsoft.com

2. **[ソリューション設定]** の下で、**[情報保護]** を選択します。

 ![](./media/l04-e1-t1-s2.png)

3. **[情報保護設定]** ページで、**[秘密度ラベル付きファイルの共同編集]** タブを選択します。

4. **[秘密度ラベル付きファイルの共同編集を有効にする]** のチェックボックスを選択します(まだ有効になっていない場合)。

   ![](./media/l04-e1-t1-s4.png)

 - ページの下部で **[適用]** を選択します。

 	![](./media/l04-e1-t1-s5.png)

		
 	> **注:** 共同編集を有効にすると、SharePoint および OneDrive に保存されたファイルの秘密度ラベルサポートも有効になります。これは SharePoint でホストされているファイルにラベルを適用し、Defender for Cloud Apps がラベルメタデータをスキャンするための前提条件です。この設定がないと、Office on the web で秘密度ボタンが表示されません。

## まとめ

このラボでは、Microsoft Purview で秘密度ラベル共同編集サポートを有効にして、SharePoint および OneDrive ファイルのラベル認識をアクティブ化しました。**[Zava-Confidential]** ラベルグループと2つの子ラベル — **[HR-Data]** および **[Financial-Data]** — を作成し、分類ドキュメントを識別するためのコンテンツマーキングを使用して構成しました。SharePoint、OneDrive、および Exchange の **[Financial-Data]** 用の自動ラベル付けポリシーを構成して、クレジットカード番号、AB ルーティング番号、および SWIFT コードを検出し、7日後に自動強制を実行するシミュレーションモードで実行されます。**[Zava-Confidential ラボel Policy]** を使用してすべてのZavaユーザーに両方のラベルを公開し、Zava HR SharePoint サイトの4つの機密 HR ドキュメントに **[HR-Data]** ラベルを手動で適用しました。Microsoft 365 Copilot および Copilot Chat ロケーションをターゲットにして **[Zava - Block HR Data in M365 Copilot]** DLP ポリシーを作成し、HR-Data ラベルを含むコンテンツへのアクセスをブロックしました。Patti Fernandes は、Microsoft 365 Copilot がラベル付き HR コンテンツを表示できるかをテストし、Patti Fernandes は結果 DLP マッチイベント用に Purview Audit ログを検索しました。Zava の機密データが分類され、Microsoft 365 Copilot はポリシーベースのアクセス制御でガバナンスされるようになりました
